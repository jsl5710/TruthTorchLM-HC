# Distilled-proxy paper — result data

Result artifacts behind the tables in `../manuscript/main.tex` (the distilled-proxy /
read-out paper). Per-seed JSON summaries; raw generations and parquet caches are omitted
(regenerable from the harness). Generated by the Stage A→D pipeline and the RQ scripts.

| folder | backs (paper section / table) |
|--------|-------------------------------|
| `results_full/aggregated.json` | read-out comparison ("the read-out dominates the objective"); 6-student scale sweep |
| `results_rq5/` | RQ5 — uncertainty-aware distillation (EDL-target × oracle × λ sweep) |
| `results_proxy_acc/` | RQ4 — proxy task accuracy vs. teacher (fluent-hallucination gap) |
| `results_dald/`, `results_disaad/` | the two distillation objectives (masked-SFT / adversarial-SFT) |
| `results_mt_estimators/` | multi-target proxy estimators (2 teachers × students × methods) |

Not bundled (too granular; regenerable): `results_rq5_pres/` (preservation sweep),
`results_mt_score/` (per-item proxy scores). Full pipeline: `hc_benchmark/` + `scripts/`.
